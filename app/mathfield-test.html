Leibniz notation (a fraction that is a derivative)

dx/dt = -y is the same row as x' = -y, and the denominator names the independent variable. It is stacked, because that is how the notation is written — but its source is dx/dt, not (dx)/(dt), which is the only spelling the engine accepts. Type one in the empty field: d x / d t = — the = steps out of the denominator by itself.

Command API — the on-screen keyboard's path

Every key below calls field.insert(text) or field.command(name) — the same two calls the phone keyboard makes. No synthetic key events. Type with the real keyboard and tap the keys in any order: they are the same path, so the row cannot tell them apart. touch mode is field.touchDriven: on a phone it keeps the OS keyboard down while the field still focuses, still shows its caret and still places it on a tap.
